# Dormstone 原创局域网卡牌对战

这是一个原创“炉石式”局域网双人卡牌游戏工程。项目只提供规则引擎、预设卡组选择、房间、对战和原创卡牌工具链，不内置或复制任何现有商业游戏的官方 IP、商标、美术、音效或完整卡牌文本。

## 运行

```bash
npm install
npm run dev
```

默认服务：

- 前端开发地址：http://localhost:5173
- 后端 API/Socket：http://localhost:4000

宿舍局域网使用时，让房主电脑运行服务，其他玩家访问房主电脑的局域网 IP。生产构建可用：

```bash
npm run build
npm run start -w @dormstone/server
```

## 第一版范围

- 本地昵称账号，第一位创建昵称的玩家自动成为管理员。
- 管理员可用网页编辑器发布、禁用原创卡牌。
- 大厅直接从 60 套预设卡组中选择一套开始对战，不需要玩家手动创建卡组。
- 服务端优先读取 `DECK_TEMPLATES_CSV`，其次读取项目目录或上级桌面目录中的 `hearthstone_curated_famous_decks.csv`；找不到 CSV 时会使用内置 60 套后备模板。
- 预设卡组会优先使用 CSV 中的核心卡名，并用结构化代理数据提供费用、攻击、生命、耐久、关键词和简化效果。
- 房间码双人对战，房主或管理员可删除等待中/已结束房间，服务端权威裁决。
- 支持刷新/短暂断线后按昵称回到房间和对局。
